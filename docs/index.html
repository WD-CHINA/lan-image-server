使用方法

  1. 下载对应平台的可执行文件
  2. 双击运行，终端会显示局域网地址和二维码
  3. 其他设备连接同一 WiFi，浏览器打开该地址
  4. 选择文件，点击上传 — 完成！

命令行参数

# 默认端口 8080，保存到 ~/Desktop/LAN-Uploads/
./lan-image-server

# 自定义端口和保存目录
./lan-image-server --port 9090 --dir "/path/to/folder"

从源码构建

git clone https://github.com/WD-CHINA/lan-image-server.git
cd lan-image-server
npm install
npm run build    # 构建当前平台的可执行文件
npm run dev      # 开发模式运行
